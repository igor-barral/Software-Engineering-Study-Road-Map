# Software-Engineering-Study-Road-Map

Repositório central do meu roadmap de estudos de engenharia de software: reúne o índice
dos repositórios de estudo, organizados por fase. Cada tema é um repositório público
próprio em `github.com/igor-barral`, com o mesmo nome da pasta, e traz teoria, código
e conclusões. Os itens marcados com `[x]` no índice já foram concluídos e publicados;
os demais ainda estão em andamento.

## Convenção de nomes

`<Tema>-<categoria>-study`, em que a categoria é uma de: `language`, `framework`, `lib`,
`softwarearchitecture`, `db`, `performance`, `security`, `devops` ou `ai`.
